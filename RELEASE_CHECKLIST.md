# GitHub release checklist

- [ ] Confirm final author list, affiliations, article status, and DOI.
- [ ] Choose and add an open-source license approved by all authors and institutions.
- [ ] Add `CITATION.cff` after the bibliographic record is final.
- [ ] Run `tests/run_smoke_tests.m` on the release commit.
- [ ] Run `tests/run_configuration_tests.m` on the release commit.
- [ ] Complete at least one full-resolution CPU run.
- [ ] Confirm that no MAT, PDF, image, CSV, or `outputs/` item is staged.
- [ ] Record the MATLAB and CPU versions used for full runs.
